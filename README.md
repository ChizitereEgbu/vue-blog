# vue-blog-app

A simple blog application built with Vue 3 and Vue Router.

## Getting started

```bash
npm install
npm run serve
```

## Project structure

```
src/
├── assets/global.css
├── router/index.js
├── views/
│   ├── HomeView.vue
│   ├── PostDetailView.vue
│   └── NotFoundView.vue
├── App.vue
└── main.js
```
